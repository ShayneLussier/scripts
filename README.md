# 🛠️ Scripts

A collection of Bash scripts designed to help you quickly configure common development environments.

---

## 📦 Available Setup Scripts

Each script is modular and easy to customize. Here are some of the current setups:

-  `setup-tailwind.sh` – Initialize TailwindCSS with the TailwindCLI.
- `setup-django.sh` – Create a virtual environment, install Django, and start a new project.
